# CLAUDE.md — браузерная онлайн-гонка «по странам мира»

Рабочее название проекта: **street-racer** (финальное название ещё не выбрано — не вшивай его в код, бери из `packages/shared/src/brand.ts`).

Это аркадные уличные гонки в браузере в духе стрит-рейсинга 2000-х: ночные города разных стран, тюнинг, онлайн-гонки. Полное ТЗ — в `docs/SPEC.md`, план работ — в `docs/PLAN.md`. Перед любой задачей прочитай оба файла.

## Правила работы (обязательно)

1. **Коммиты (решение владельца от 25.11.2026):** Claude коммитит и пушит в `main` сам — один коммит на задачу из PLAN.md. Не выполняй `git reset --hard`, `git rebase`, force-push.
2. **Ничего не удаляй.** Если файл или папка больше не нужны — напиши список «к удалению», владелец удалит сам.
3. **Режим до 02.12.2026:** работа без остановок по фазам 0–3, без ожидания «старт» перед задачей. План задачи коротко фиксируется в сообщении коммита.
4. Работай маленькими шагами: одна задача из PLAN.md = один законченный, проверенный результат.
5. После задачи: запусти тесты и линтер, отметь задачу в `docs/PLAN.md` (`[x]`), допиши решения в `docs/DECISIONS.md`.
6. Не добавляй зависимости «на всякий случай». Каждая новая библиотека — строка в `docs/DECISIONS.md` (зачем, лицензия).

## Юридические ограничения (нарушать нельзя)

- Никаких названий, логотипов, шрифтов, интерфейса, карт, моделей, звуков и музыки из Need for Speed или других игр EA. Слова «Need for Speed», «NFS», «Underground» не используются в коде, ассетах и текстах.
- Никаких реальных марок и моделей машин: только вымышленные (`packages/shared/src/cars/`).
- Ассеты — только собственные или CC0 (например, Kenney). Каждый внешний ассет записывается в `docs/ASSETS.md`: файл, источник, лицензия.
- Музыка игрока воспроизводится только локально в браузере; аудиофайлы игрока никогда не отправляются на сервер.
- Данные карт из OpenStreetMap — с атрибуцией «© участники OpenStreetMap» (ODbL).

## Стек

| Часть | Технологии |
|---|---|
| Монорепозиторий | pnpm workspaces, TypeScript strict, ESLint + Prettier |
| Клиент `apps/client` | Vite, Three.js (WebGL2), Rapier (`@dimforge/rapier3d-compat`), lil-gui для отладки |
| Общий код `packages/shared` | Типы, протокол сети, конфиги машин и трасс, константы |
| Физика `packages/physics` | Модель машины (raycast vehicle + аркадные помощники), без зависимостей от рендера |
| Сервер гонок `apps/race-server` | Node.js + TypeScript, Colyseus (или ws — решение в фазе 3) |
| API и метаигра `apps/api` | Spring Boot 3, Java 21, PostgreSQL, Redis (с фазы 5) |
| Тесты | Vitest (TS), JUnit 5 (Java), Playwright — дымовые тесты клиента |

## Команды

```bash
pnpm install
pnpm dev            # клиент на http://localhost:5173
pnpm test           # все тесты TS
pnpm lint
pnpm --filter race-server dev
```

## Принципы кода

- Физика считается с фиксированным шагом 60 Гц, отдельно от рендера. Никакой логики, зависящей от FPS.
- Все параметры машины — в JSON-конфиге (`packages/shared/src/cars/*.json`), не в коде.
- Физика детерминирована при одинаковом вводе: запись ввода → повтор → то же время финиша.
- Код физики и протокола покрыт тестами. Рендер и UI — дымовыми тестами.
- Производительность: бюджет кадра 16 мс на ПК, 33 мс на телефоне. Не добавляй тени и постобработку без пресета качества.
