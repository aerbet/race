## Как запускать и проверять

```bash
pnpm install
pnpm dev                                # клиент :5173
pnpm test                               # 455 тестов TS, ~1 мин (физика долгая)
npx eslint .
npx prettier --check --end-of-line auto .
pnpm -s typecheck
pnpm e2e                                # дымовые тесты Playwright (поднимает клиент и race-server)
cd apps/api && mvn -q -B test           # 32 теста JUnit, нужны PostgreSQL и Redis
```

- **Java-тесты в облачной среде.** Нужны PostgreSQL 16 и Redis: пользователь `racer`/`racer`, базы `racer` и `racer_test`. Перед прогоном пересоздать тестовую базу:
  ```bash
  psql -h localhost -U postgres -c "drop database if exists racer_test;" -c "create database racer_test owner racer;"
  ```
  Скрипт запуска баз лежал в scratchpad прошлой сессии и, скорее всего, не сохранился. Если окружение новое, базы надо поднять заново.
- **Запуск API:** `cd apps/api && mvn -q spring-boot:run` (порт 8080).
- **`apps/api/dump.rdb`.** Локальный Redis перезаписывает этот файл. Не коммить его: верни командой `git checkout -- apps/api/dump.rdb`. Файл в списке «к удалению».
- **Проверка в браузере.** Удобно через Playwright:
  - флаги `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`;
  - приложение доступно как `window.__app`; заезд запускается через `window.__app.start({...})`;
  - `localStorage['sr:dispatcher-seen']='1'` пропускает диалог «Диспетчера».
  - В облачном браузере FPS низкий, поэтому авто-качество переключается на `low`. Для снимков открывай `?q=high`.

## Ключевые решения, которые легко сломать

- **Образы.** `resolveVisual()` (shared) накладывает надетый образ (`visual.look`) поверх отдельных слотов и читает старый `vinyl` как `livery`. Выбор отдельной детали в гараже или ателье отправляет `look: 'none'`.
- **Ротация витрины.** Считается только на сервере (`ShopRotation`, зависит от даты UTC): обычные предметы есть всегда, из остальных — 6 штук, среди них 1 образ. Покупка вне витрины даёт 409 `not_in_rotation`.
- **YouTube.** Играет, только если плеер развёрнут, вкладка видна и плеер виден хотя бы на 50 % (`mayPlay`). Это требование YouTube, не ослаблять. Если YouTube не загрузился за 5 с, включается радио.
- **Stars.** Телу вебхука не верим. Начисление происходит только после того, как транзакция с нашим payload найдена в `getStarTransactions`, а там смотрятся последние 100 транзакций. При большом потоке оплат нужно хранить `telegram_payment_charge_id`.
- **Коллайдеры города.** Формат `[cx, cz, hx, hz, yaw, h, y0?]`: с `y0` коробка считается полом (настил), а не стеной.
- **Автозамер FPS.** Не идёт на паузе и в фоторежиме. Раньше на паузе он перезапускал заезд.
