## Как устроено (главное)

### 3D-конвейер (`art/`)

- Всё 3D строится Python-скриптами Блендера по JSON-спецификациям. Ручные правки `.blend` не используются.
  - `art/scripts/cars/`: `build_car.py` (точка входа), `body.py` (кузов-лофт), `car.py` (детали и библиотека стилей), `kits.py`, `wheels.py`, `silhouette.py`.
  - `art/scripts/city/`: `trim_sheet.py` (атлас), `build_modules.py` (модули и реквизит), `landmarks.py`, `render_street.py`.
  - `art/scripts/track/`: `dressing.py`, `terrain.py`, `map.py`.
  - `art/scripts/lib/`: общие модули (сцена, материалы, UV, LOD, экспорт, проверки, рендеры, AO).
- Спецификации:
  - машины — `art/specs/cars/<id>.json`;
  - диски — `art/specs/wheels/`;
  - ориентиры городов — `art/specs/city/<kit>.json`;
  - сплайны трасс — `art/specs/track/<id>.json`, генерируются командой `pnpm track:export`.
- Команды (подробно — `art/README.md`):

  ```
  pnpm art:car <id> [--publish] [--no-render]   # машина + её киты
  pnpm art:wheels [--publish]
  pnpm art:city <moscow|tokyo> [--no-render]     # атлас, модули, реквизит, ориентиры → public/cities/kits/<kit>
  pnpm track:export all
  pnpm art:track maps | dressing | terrain jp_touge
  pnpm art:validate
  ```

- Опубликованные ассеты:
  - машины — `apps/client/public/cars/<id>/{base,kit_*}.glb`;
  - колёса — `public/wheels/`;
  - наборы городов — `public/cities/kits/`;
  - города — `public/cities/<id>/`;
  - оформление и рельеф — `public/tracks/`;
  - карты — `public/maps/`.
- Рендеры для проверки лежат в `art/renders/<id>/` (`sheet.png`, `kits.png`, `street_night.png` и т. д.).

### Города

- В `osm-to-city` контур дома подбирается под модуль набора. Длинные дома собираются из нескольких секций, периметральные кварталы — секциями вдоль сторон.
- Реквизит расставляется вдоль улиц, ориентиры получают зону без домов.
- В `city.json`: `kit`, `modules`, `tiles[].instances`, `landmarks`.
- Клиент: `apps/client/src/city/city-view.ts` — по одному `InstancedMesh` на модуль и LOD.
- Реальные районы:

  ```
  cd tools/osm-to-city
  npx tsx src/cli.ts --bbox 55.751,37.596,55.769,37.628 --id moscow_center --name "Москва, центр" --kit moscow --auto-tracks mskc
  npx tsx src/cli.ts --bbox 35.684,139.692,35.702,139.714 --id tokyo_shinjuku --name "Токио, Синдзюку" --kit tokyo --style tokyo --auto-tracks tyos
  ```

  Сырые данные OSM кэшируются в `tools/osm-to-city/data/`: в git они не попадают, `--refresh` скачивает заново (только с разрешения владельца). Трассы по улицам строит `tools/osm-to-city/src/routes.ts`.

### Управляемость (последняя работа)

- Код: `packages/physics/src/vehicle.ts`. Новые блоки `assists` в конфиге машины (схема — `packages/shared/src/cars/schema.ts`, значения явно во всех 14 JSON):
  - `gripSteer` (`latG` 2.0, `extraDeg` 2.5) — угол колёс на скорости в пределах аркадного сцепления;
  - `stability` (`yawGain` 7, `maxSlipDeg` 9, `slipRate` 5, `gripRate` 3) — работает как ESP, траектория идёт за носом;
  - `handbrake` (`straightBrake` 0.8, `turnBrake` 0.2, `extraAngleDeg` 8) — пробел без руля тормозит, с рулём даёт занос с пределом угла;
  - `driftInit.autoTriggers` = false — срыв только ручником с газом (газ + пробел + руль) или приёмом «тормоз+газ+руль». В дрифт-гонке автосрыв включает опция машины `driftMode`;
  - `handbrake` сейчас: `straightBrake` = `turnBrake` = 1, `driftNeedsThrottle` = true — пробел без газа резко тормозит;
  - `brakeAssist.extraG` 0,6 — аркадное дополнительное замедление (со 100 км/ч — 1,6 с, со 200 — ~3,1 с).
- Также поменялись `driftExit.recoverRate` (5) и `steering.keyboardRate` / `keyboardReturnRate` (7 / 10).
- Серпантин (`packages/physics/src/level.ts`, `sim.ts`):
  - коллайдер отбойника 2,8 м и уходит на 1,5 м ниже полотна (видимая часть — прежние 1,4 м);
  - при ударе о стену машину не подбрасывает;
  - вылетевшая машина сразу возвращается на трассу.
- Нормы — `packages/physics/src/handling.test.ts`, на все машины. Замеры «до/после»: `MEASURE=1 npx vitest run packages/physics/src/dev/handling-measure.test.ts` (и `dev/wall-measure.test.ts`).
