# ART_BRIEF — технические требования к 3D (машины и город)

Модели делает Claude в Блендере по `docs/BLENDER_PLAN.md`. Этот документ — требования к результату: что должно получиться и как проверяется.

## Проект

Браузерная аркадная гонка, ночной стрит-рейсинг. Движок — Three.js (WebGL2), работает на ПК и телефонах. Стиль — стилизованный реализм: чистые формы, яркие ночные огни, без фотореализма.

## 1. Машины-«двойники»

Как в GTA: игрок с первого взгляда узнаёт легенду, но это не копия реальной модели. Мы не используем ни названий, ни логотипов, ни 3D-моделей реальных машин.

**Сохраняем:** класс и пропорции (длина, высота, колёсная база, посадка), общий характер силуэта, «настроение» машины.

**Обязательно меняем (не меньше 4 пунктов на машину):**
- форма и рисунок передних и задних фар;
- решётка радиатора и воздухозаборники (никаких «ноздрей», фирменных решёток и форм, которые являются визитной карточкой марки);
- линии боковины и форма окон (мягко, но заметно);
- бамперы и диффузор;
- зеркала, ручки, выхлоп;
- никаких эмблем — только наши вымышленные марки.

Хороший приём — смешивать черты двух машин одного типа. Модель, которую можно принять за оригинал на скриншоте, не принимается.

Запрещено: покупать или скачивать модели реальных машин и «перерисовывать» их; использовать чертежи (blueprints) и фото реальных машин для точной обрисовки. Можно: брать открытые габариты (длина, ширина, высота, колёсная база, колея, размер колёс) как стартовые параметры.

### Технические требования к машине

| Параметр | Значение |
|---|---|
| Формат сдачи | `.blend` (исходник) + `.glb` (glTF 2.0) |
| Масштаб и оси | 1 юнит = 1 метр. В игре перёд машины смотрит в **−Z**, верх +Y (так в `packages/physics` и `render/car.ts`). В Блендере это значит: нос машины по **+Y**, верх +Z — экспортёр glTF сам переведёт оси. Начало координат — на земле, по центру между осями |
| Полигоны LOD0 | 25–45 тыс. треугольников (кузов + детали), колесо ≤ 3 тыс. |
| LOD1 / LOD2 | ~40% / ~10% от LOD0 |
| Текстуры | PBR (base color, normal, ORM), 2048 для кузова, 1024 для колёс; атласы |
| Маска покраски | Отдельная текстура: R — основной цвет, G — второй цвет, B — хром/карбон |
| UV | `uv0` — текстуры без перекрытий; `uv1` — чистая развёртка кузова под ливреи (бока, капот, крыша, багажник — крупными островами без искажений) |
| Стёкла | Отдельный материал, слегка тонированные |
| Фары | Отдельные меши `lights_front`, `lights_rear` с эмиссией |
| Интерьер | Упрощённый (виден через стекло), ≤ 3 тыс. треугольников |

### Структура узлов (имена строго такие)

```
car_root
├─ body              (кузов без съёмных деталей)
├─ hood
├─ bumper_front
├─ bumper_rear
├─ skirts
├─ spoiler           (может быть пустым)
├─ glass
├─ lights_front
├─ lights_rear
├─ interior_low
├─ exhaust
├─ wheel_FL / wheel_FR / wheel_RL / wheel_RR   (центр в оси вращения)
├─ brake_FL / brake_FR / brake_RL / brake_RR   (не вращаются)
└─ socket_spoiler, socket_exhaust, socket_plate_front, socket_plate_rear  (пустые объекты-точки крепления)
```

### Кузовные киты (скины)

На каждую машину: базовый вид + 3 кузовных кита (например: «Уличный», «Трековый», «Дрифт»). Кит = свои `bumper_front`, `bumper_rear`, `skirts`, `spoiler`, `hood`, без изменения `body`. Плюс 6 общих моделей дисков в двух диаметрах.

## 2. Город (первый — «Москва, зима, ночь»)

- Модульный набор: 15–25 зданий (сталинки, панельные дома, стеклянные башни, торговые центры), 10 модулей дорог и перекрёстков, фонари, остановки, ограждения, рекламные щиты с вымышленными брендами.
- Окна ночью — эмиссивный атлас с вариантами освещённости.
- Здания ≤ 2–5 тыс. треугольников на модуль, общие атласы 2048.
- Улицы берём из OpenStreetMap (импорт через Blender-аддон для OSM), модули расставляются по контурам; узнаваемые места — стилизованно, без точного копирования современных зданий.
- Сдача: `.blend` + `.glb` блоками 256×256 м, ≤ 3 МБ на блок после сжатия.
