## Фаза 7. Производительность и первые впечатления (≈ 1 неделя)

- [x] **7.1 FPS на телефоне.** На скриншотах владельца — 10 fps с пресетом `high` на iPhone. Пресет выбирается по User-Agent, но iPad и «полная версия сайта» в Safari выдают себя за Mac. Сделать: (а) дополнительно считать устройство мобильным при `navigator.maxTouchPoints > 1`; (б) замер первых 3 с — если < 40 fps, переключиться на `low` и запомнить; (в) в `low` разрешение рендера 0,75 и общий атлас окон вместо отдельных мешей; (г) счётчик draw calls в `?debug=1`.
  Готово, когда: 30+ fps на iPhone 12-го поколения и среднем Android 2023 года в городе.
- [x] **7.2 Строку `fps · мс · high` показывать только с `?debug=1`.**
- [x] **7.3 Тексты.** Сейчас русские строки зашиты в 34 файла клиента и в API. Сначала вынести все строки в `packages/shared/src/i18n/ru.json` и `en.json` (клиент + сообщения API, которые видит игрок), затем переписать по `docs/COPY_GUIDE.md`. Начать с магазина (`meta/shop-screen.ts`: «за жетоны — только внешний вид…», «Telegram · крипта (USDT/TON)»), меню и HUD.
  Готово, когда: поиск по `apps/client/src` не находит кириллицы вне комментариев; все строки прошли чек-лист COPY_GUIDE.
- [x] **7.4 Оплата.** Сейчас есть Crypto Pay (USDT/TON) и СБП через ЮKassa. Важно: ЮKassa подключается только для юрлица или ИП в России — владелец из Кыргызстана, решение о юрлице за ним. Добавить провайдер **Telegram Stars** (для Mini App и для игроков из любых стран) по тому же интерфейсу `PaymentProvider`; в интерфейсе — цена в валюте игрока и одна кнопка «Купить», способ оплаты — на следующем шаге.

## Фаза 8. Музыка: YouTube-плейлисты (≈ 1 неделя)

Сейчас есть только локальный плеер (`audio/music.ts`). Добавляем YouTube **только официальным IFrame Player API**. Требования YouTube (нарушение = блокировка ключа):

- плеер видим на экране, область не меньше 200×200 px, стандартные элементы управления и реклама не скрываются и не перекрываются;
- нельзя отделять звук от видео, нельзя проигрывать при свёрнутой или закрытой вкладке — на `visibilitychange` ставим паузу;
- автозапуск только когда плеер виден больше чем наполовину; не больше одного автозапускаемого плеера на экране;
- перед показом проверять, что видео разрешено встраивать (YouTube Data API), недоступные треки пропускать.

Задачи:

- [x] **8.1 Мини-плеер** — сворачиваемая карточка 200×200+ в углу (в гараже и меню — раскрыта; в гонке — минимальный разрешённый размер, не перекрывая HUD). Наши кнопки управления — рядом с плеером, не поверх него.
- [x] **8.2 Свои плейлисты:** «Вставь ссылку на плейлист YouTube», разбор `list=…`, до 10 плейлистов в профиле.
- [x] **8.3 Рекомендованные:** `packages/shared/src/music/featured.json`, первый элемент `{ "id": "PLDE0DBBFAA8E2F771", "title": "Гоночная классика 2004", "subtitle": "Тот самый саундтрек" }`. Без слов NFS / Need for Speed / Underground. Плейлист фанатский и может исчезнуть — при ошибке API карточка скрывается.
- [x] **8.4 Одно меню «Музыка»:** Радио игры · Мои файлы · YouTube. Режим стримера отключает YouTube.
- [x] **8.5 Запасной вариант:** YouTube не загрузился за 5 с → «YouTube сейчас недоступен — включи радио или свои треки», переключение на радио.
