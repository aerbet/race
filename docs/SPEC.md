# SPEC — выжимка ТЗ для разработки

Источник: документ «ТЗ: браузерная онлайн-гонка по странам мира» (25.11.2026). Здесь только то, что нужно для кода.

## Продукт

- Аркадный ночной стрит-рейсинг в браузере (ПК в приоритете, телефон — упрощённая графика).
- Мировой тур: у каждой страны открытый город ~2×2 км и 6–10 трасс. На запуске: Россия (зимний мегаполис по мотивам Москвы) и Япония (неоновый город по мотивам Токио + горный серпантин).
- Онлайн: лобби до 8 игроков, свободная езда до 16 в зоне, рейтинг Эло по классам, таблицы рекордов с «призраками», еженедельный Гран-при.
- Машины вымышленные, две эпохи: «нулевые» (лёгкие, большой запас тюнинга) и «2026» (быстрее с завода, тяжелее, есть электро). Индекс мощности PI 100–999 → классы D/C/B/A/S.
- Тюнинг: двигатель, турбо, трансмиссия, подвеска, шины, тормоза, нитро, облегчение — по 4 уровня. Визуал: бамперы, спойлеры, диски, краска, неон, винилы.
- Персонажи (взрослые, обоих полов) дают заезды-задания и сюжетные главы. Рейтинг игры 12+/16+.
- Монетизация: боевой пропуск (8 недель), косметика, клубная подписка. В рейтинговых гонках деньги не дают преимущества в скорости. Никаких лутбоксов за деньги.

## Физика вождения (главное требование)

Ощущение как в аркадных стрит-рейсингах середины 2000-х: плавно, отзывчиво, лёгкий дрифт, мягкие столкновения. Не симулятор.

- Raycast vehicle: 4 луча подвески + твёрдое тело кузова. Упрощённые кривые сцепления.
- Фиксированный шаг 60 Гц, одинаковое поведение при 30/60/120 FPS.
- Аркадные помощники (каждый включается и настраивается в конфиге):

| Помощник | Требование |
|---|---|
| Руль по скорости | Угол поворота колёс уменьшается с ростом скорости |
| Помощь в повороте | Дополнительный момент рыскания при удержании руля |
| Срыв в дрифт | Ручник, или сброс газа с рулём, или тормоз + газ → снижение бокового сцепления задней оси |
| Удержание дрифта | Автоконтрруление держит угол 20–55°; разворот только при явной ошибке |
| Выход из дрифта | Сцепление возвращается плавно, без «выстрела» в сторону |
| Нитро | +25–40 % тяги на 2–4 с, FOV и размытие; заряжается дрифтом, обгоном, прыжками |
| Столкновения | Скольжение вдоль стен, без поломок; автосброс на трассу через 3 с |
| Стабилизация в воздухе | Машина приземляется на колёса |

- Камера: на пружине, FOV 65°→85° со скоростью, лёгкая тряска; виды — близко, далеко, с капота.
- Ввод: клавиатура (плавное доведение руля), геймпад (аналог + триггеры, мёртвая зона), сенсор (кнопки или наклон, автогаз, автодрифт). Задержка ввода ≤ 1 кадра.
- Приёмка: слепой тест 10–20 игроков, оценки 1–5 по «плавность», «отзывчивость», «дрифт», «ощущение скорости», «хочется ещё»; цель ≥ 4,0 по каждому пункту.

## Сеть

- Сервер гонки ведёт старт, порядок чекпоинтов, финиш и награды.
- Тик сервера 20–30 Гц. Своя машина — с предсказанием, чужие — с интерполяцией. Комфортно при пинге до 150 мс.
- Проверки правдоподобия: скорость ≤ максимума машины, реальные перемещения между пакетами, время участка ≥ теоретического минимума.
- Топ-100 рекордов принимается вместе с записью ввода (для повторной проверки).

## Производительность и размер

- ПК: 60 fps на средней видеокарте. Телефон: 30 fps на среднем Android 2023 года.
- Первая загрузка ≤ 40 МБ, страна ≤ 80 МБ. glTF + meshopt/Draco, текстуры KTX2, город подгружается блоками 256 м.
- От открытия сайта до руля ≤ 90 с при первом заходе и ≤ 20 с с кешем.

## Звук

- Web Audio. Звук двигателя — кроссфейд сэмплов по оборотам и нагрузке; типы I4, V6, V8, роторный, электро.
- Плеер своей музыки: выбор файлов (File System Access API, запасной вариант — input type=file), плейлист, shuffle. Только локально.
